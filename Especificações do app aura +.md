**Especificações**

	Desenvolvimento de um aplicativo Android com armazenamento local utilizando SQLite, implementando as operações CRUD, me de sugestões de projeto para eu desenvolve em equipe. Pode ser complexo quanto maior, mais conhecimento, mas temos que entregar para o dia 16/11 tem que ser algo que de para entregar até lá.

**Requisitos Obrigatorios**  
O aplicativo deverá atender aos seguintes requisitos:

1. Utilizar Java e Android Studio para o desenvolvimento.  
2. Utilizar SQLite como banco de dados local.  
3. Criar pelo menos uma tabela principal contendo no mínimo 10 colunas (campos), além da chave primária.  
4. Criar uma estrutura de banco de dados coerente com o cenário escolhido.  
5. Implementar as quatro operações CRUD:  
   * Create (Cadastrar): permitir a inclusão de novos registros.  
   * Read (Consultar): permitir a consulta e listagem dos registros cadastrados.  
   * Update (Atualizar): permitir a edição de registros existentes.  
   * Delete (Excluir): permitir a exclusão de registros cadastrados.  
6. Desenvolver telas próprias e separadas para as funcionalidades do aplicativo. Preferencialmente, utilizar Activities diferentes para cadastro, consulta e edição.  
7. Criar formulários com campos adequados ao cenário escolhido.  
8. Apresentar os registros cadastrados em uma tela de consulta/listagem.  
9. Implementar validações básicas dos campos obrigatórios.  
10. Exibir mensagens de confirmação e retorno das operações realizadas.  
11. Garantir a persistência dos dados, mantendo os registros armazenados mesmo após fechar e abrir novamente o aplicativo.  
12. Implementar a navegação entre as telas do aplicativo.
